# A simple chat
---
## Requirements

For development, you will only need Node.js and a node global package, Yarn, installed in your environement.

## Install

    $ git clone https://github.com/rogerkeithi/tmaior-test-rogerkeithi
    $ cd tmaior-test-rogerkeithi
    $ npm install

## Configure app

You'll need to create a `.env` file and set the enviroment variable named `DATABASE_URL` with the mongo url connection string.

## Build the project

Use this command to build the project

    $ npm run build

## Running the project in staging

Use this command to run the application in staging

    $ npm run start:dev

## Running the project in production stage

Use this command to run the application

    $ npm run prod
